### 🚀 Featured project

**[Pathfinding Visualizer](https://github.com/abshakebidari-design/pathfinding-visualizer)** · [Live demo](https://abshakebidari-design.github.io/pathfinding-visualizer/)

An interactive web app that animates how A\*, Dijkstra, BFS, DFS and Greedy Best-First search find a path through a grid. Draw walls and weighted terrain, generate mazes, and compare all algorithms side by side. Built with plain JavaScript, with automated tests running on GitHub Actions.
